## 五、出错与失误（照实）

1. **437065 报错退出**：`AttributeError: 'Qwen3_5DecoderLayer' object has no attribute 'self_attn'`，出在 `src/models/attn_switch.py` 第 22 行。原因是 Qwen3.5 的第 0 层是 Gated DeltaNet。按停止条件先停下报告；planner 同意修法后，改为只在带 self_attn 的层上挂 hook，一层都没有就报错。新增 `tests/test_attn_switch.py`：13 个全注意力模型 hook 集合不变；Qwen3.5 只挂在 3、7……层，fp32 补丁生效（5e122e8）。重交后无出错。
2. **误交作业 437051**：第一次跑 `tests/test_slurm.py` 时，新的 `submit.sh` 因为 shell 的 noclobber 没写进去，测试调用了旧版脚本，真的提交了一个 echo 作业。我在它运行前取消了；后续提交被每人 4 个作业的上限拒掉，没有别的误交。
3. 抠图库 v2 / v3 的几个脚本错误，都修好并重跑了（见第六节）：cut 阶段 val 候选与自身图像匹配被误判泄漏；CLIP 结果写盘时出现 numpy bool 报错，1.5 小时 CPU 白跑；tune 阶段 JSON 键类型报错。
